# Como instalar o ODA·ADS como app

## Opção 1 — Instalar direto pelo navegador (mais fácil)

**Android (Chrome / Samsung Internet):**
1. Abra https://odaads.lumvix.com.br/ no navegador
2. Toque no botão **"Instalar App"** no topo do site (ou no menu ⋮ → **"Adicionar à tela inicial"**)
3. Confirme — o app instala como um app nativo, com ícone próprio

**iPhone / iPad (Safari):**
1. Abra o site no Safari
2. Toque no ícone de compartilhar (o quadrado com uma seta para cima)
3. Toque em **"Adicionar à Tela de Início"**
4. Confirme

**Windows / Mac (Chrome / Edge):**
1. Abra o site
2. Clique no ícone de instalar na barra de endereço (ou no botão "Instalar App")
3. Confirme

## Opção 2 — Gerar um APK real via PWABuilder (gratuito)

1. Acesse **https://pwabuilder.com**
2. Cole a URL `https://odaads.lumvix.com.br` e clique em **Start**
3. Clique em **Android → Download Package**
4. Extraia o ZIP e siga as instruções para assinar o APK
5. Instale o `.apk` no celular via **Configurações → Instalar apps desconhecidos**

## Compatibilidade

| Dispositivo | Suporte |
|---|---|
| Android 5+ | Chrome, Samsung Internet |
| iPhone/iPad iOS 11+ | Safari (Adicionar à Tela de Início) |
| Windows 10/11 | Edge, Chrome |
| macOS | Safari, Chrome |
| Tablet Android | Chrome |

## Funciona offline?

Sim. O Service Worker guarda em cache o app inteiro (módulos, quiz, flashcards). Depois da primeira visita com internet, o conteúdo continua acessível sem conexão.
